# Trámite de certificación de discapacidad — San Pedro

Proyecto piloto de la Alcaldía Municipal de San Pedro, Valle del Cauca. Portal ciudadano y gestión de solicitudes por personal autorizado de Salud. No usar información real hasta completar la habilitación institucional y las pruebas de seguridad.

El certificado oficial se expide por el procedimiento competente en el RLCPD; esta aplicación gestiona la solicitud y su entrega.

No subir al repositorio credenciales, historias clínicas, documentos personales ni certificados.
